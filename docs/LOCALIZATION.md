# 다국어 랜딩페이지 운영 매뉴얼

모든 공개 화면 업데이트 시 `.agents/skills/maintaining-locales/SKILL.md`를 적용합니다. 랜딩·문의·개인정보·입력 오류·성공 안내·메타데이터가 같은 의미를 유지해야 합니다.

## 언어와 대상 시장

지원 언어와 원어 표기는 `src/lib/locales.mjs`가 기준입니다. 언어와 국가는 일대일이 아닙니다. 시장 목록은 사업상 가설이며 실제 유입 실적을 뜻하지 않습니다.

## 접속 규칙

1. `/ja/privacy`처럼 언어가 명시된 URL은 해당 언어로 엽니다.
2. `/`, `/contact`, `/privacy`는 직접 선택한 `remo_locale` 쿠키를 먼저 사용합니다. 쿠키는 이 사이트의 언어 선택만 기억하며 1년간 유지합니다.
3. 첫 방문은 브라우저가 보낸 `Accept-Language`를 가중치 순서로 비교합니다. `fr-CA`는 `fr`, `pt-BR`는 `pt`, `zh-Hant`·`zh-TW`·`zh-HK`·`zh-MO`는 번체, `zh-Hans`·`zh-CN`·`zh-SG`는 간체입니다.
4. 브라우저 언어 정보 자체가 없으면 간체입니다. 지원 언어와 일치하지 않으면 영어입니다. `q=0`은 선택하지 않습니다.
5. 국가 IP 조회는 하지 않습니다. 관리자·API·정적 파일·존재하지 않는 경로는 자동 언어 이동 대상이 아닙니다.

기존 `/` 간체 URL과 `/ko` URL은 계속 사용할 수 있습니다. 언어 메뉴는 명시적 `/zh-CN`, `/en` 등으로 이동하며 현재 페이지, 쿼리, 캠페인, 문의 분야, 앵커를 유지합니다. 직접 방문한 명시적 URL 자체는 쿠키를 덮어쓰지 않습니다. 사용자가 메뉴에서 고른 언어만 저장합니다.

## 번역 파일과 코드

- `src/lib/messages/<locale>.json`: 언어별 독립 파일. 중국어 원문이 공통 키입니다.
- `src/lib/messages.ts`: 서버에서 선택한 사전만 읽고 영어를 방어적 기본값으로 합칩니다.
- `LocaleProvider.tsx`: 해당 언어 사전을 전달받아 `t()`와 `path()`를 제공합니다.
- `src/app/[locale]`: 모든 언어의 공통 페이지와 HTML lang/dir.
- `src/proxy.ts`: 공개 기본 URL만 언어 자동 선택.
- `src/lib/locale-metadata.ts`: 페이지별 제목·설명·canonical·hreflang. 운영 도메인을 바꾸면 `NEXT_PUBLIC_SITE_URL`을 설정합니다.
- `scripts/check-locales.mjs`: 20개 사전의 키·값·공개 t() 호출 누락 검사. `npm run build`에서도 자동 실행하여 번역 누락 시 빌드를 중단합니다. 새 문장은 원문 사전과 모든 번역에 함께 추가합니다.

신규 섹션, 수정 문장, 동의 안내, 오류 메시지를 변경할 때 모든 언어에 같은 의미를 반영합니다. 자동 검사 통과는 의미·법률 검수 통과를 뜻하지 않습니다. 현재 번역은 독립적인 원어민·현지 법률 검수를 받지 않았습니다. 공급 역량·총판권·보장된 성과를 번역 과정에서 추가하지 않습니다.

## 검증

`npm run check:locales`, `node --test tests/web/*.test.mjs`, `npm run lint`, `npm run build`를 실행합니다. 브라우저에서 간체 기본값, 지원/미지원 언어, 쿠키 우선순위, 수동 전환, 모든 언어의 랜딩/문의/개인정보 및 메타데이터를 확인합니다. 320px·390px·PC 폭에서 긴 제목, 줄 간격, 문의 버튼, 오류 문구와 아랍어 RTL을 확인합니다. 실제 문의·메일을 보내지 말고 테스트 응답으로 상태를 확인합니다.

문의 레코드에는 검증된 `locale`과 `landingPath`를 기록합니다. 관리자 화면과 운영자가 설정하는 이메일 템플릿은 공개 페이지 번역 범위와 별개입니다.

브라우저 자동 검증 스크립트는 `scripts/check-locales-browser.mjs`입니다. Playwright와 Chromium이 준비된 개발 환경에서 프로덕션 서버를 실행한 다음 `CHROMIUM_PATH=/usr/bin/chromium npm run check:locales:browser -- http://127.0.0.1:3002`를 실행합니다. Chromium 위치가 다르면 해당 경로를 지정합니다. 문의 API 응답은 브라우저에서 가로채므로 실제 데이터 저장·메일 발송은 하지 않습니다.
